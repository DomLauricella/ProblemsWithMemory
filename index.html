02 / WHY WE FORGET

Common memory problems

Encoding failure

Sometimes information never gets stored well. You might forget a name because you were distracted when you heard it.

Retrieval failure

A memory can be stored but hard to recall. Knowing a word but being unable to say it is a familiar example.

Interference

Memories can compete. Proactive interference happens when old information gets in the way of new learning. Retroactive interference happens when new information makes older information harder to recall.

Misinformation effect

Details heard after an event can change how you remember it. A misleading question can influence an eyewitness's account.

Source: OpenStax Psychology 2e, Section 8.3
